# Dental Clinic Website

A modern, responsive dental clinic website built with React, Express, and Firebase.

## Features
- Appointment booking
- Service showcase
- Doctor profiles
- Admin dashboard for managing services, doctors, and appointments
- Multilingual support

## Tech Stack
- Frontend: React, Tailwind CSS, Framer Motion
- Backend: Express, Vite (for dev)
- Database: Drizzle ORM (PostgreSQL), Firebase
- UI Components: Shadcn UI

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`
